# Консоль кода для 1C:Предприятие

**Two‑mode code console** — обработка, позволяющая exécuter du code arbitrary tanto sur le client que sur le serveur в фоновом режиме с защитой от зависаний и поддержкой файловых баз.

## Возможности

- **Двухрежимный запуск**
  - *Клиентский режим* (КонтекстИсполнения = 0): код выполняется локально в браузере/клиенте, результат сохраняется в переменную `РезультатВыполнения`.
  - *Серверный режим* (КонтекстИсполнения = 1): код передается на сервер через фоновые задания (`ФоновыеЗадания.Выполнить`), возвращается идентификатор задания, статус проверяется через `ПроверитьСтатусЗадания`.
- **Защита от зависаний**
  - Таймаут по умолчанию **30 seconds** (`Таймаут = 30`). При превышении таймаута команда останавливается, сообщение `ПРЕВЫШЕН ТАЙМАУТ`.
- **Сохранение контекста**
  - Контекст исполнения сохраняется в временное хранилище и извлекается обратно (`ПолучитьКонтекстССервера`), чтобы данные не терялись между клиентом и сервером.
- **Поддержка файловых баз**
  - Внутри обработки используются `РегламентныеЗадания.ВыполнитьОбработкуЗаданий()` для эмуляции фоновых заданий в файловых базах, где стандартные фоновые задания недоступны.
- **Проверка прав**
  - Процедура `ПроверитьПраваНаСервере` (по умолчанию возвращает `Истина`, в продакте следует добавить реальную проверку ролей).
- **Обработка отмены и таймаута**
  - Возможность остановить выполняющееся задание командой `КомандаОстановить` и сбросить идентификатор.

## Как использовать

1. Откройте обработку **КонсольКода** в конфигураторе 1C:Предприятие.
2. Выберите режим исполнения (клиент/сервер) с помощью чекбокса **Контекст исполнения**.
3. Введите произвольный код в поле `ТекстКода`.
4. Нажмите **Команда Выполнить**.
5. Результат появится в поле `РезультатВыполнения` или будет доступен через лог фонового задания.

## Файлы в репозитории

- `КонсольКода.xml` — метаданные обработки (ExternalDataProcessor, описание формы).
- `КонсольКода/` — папка с формой и модулем `Module.bsl`, содержащий весь исходный код, описанный выше.
- `КонсольКода.epf` — исходный файл обработки (может быть загружен в конфигуратор для редактирования).
